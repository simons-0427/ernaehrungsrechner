Nutrition Optimizer | Lokal im Browser

Ideale Ernährung.

Vergleiche Lebensmittel, setze Tagesziele und berechne den günstigsten Plan, der sie trifft. Editierbar im Browser, ohne Konto.

Lebensmittel-Datenbank

Suchen, filtern, Werte editieren. Die Tabelle lädt nur die sichtbare Seite, auch wenn viele Nährwertspalten offen sind.

Änderungen an der Datenbank werden automatisch lokal in diesem Browser gespeichert. Werte gelten pro 100 g / 100 ml beziehungsweise pro 1 Stück / 1 Tropfen. Eine leere Zelle entspricht 0.

Auf dem Smartphone zeigt die Tabelle die wichtigsten Werte. Tippe auf i, um alle Nährwerte eines Lebensmittels anzusehen.
