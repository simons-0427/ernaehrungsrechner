# Ernährungsrechner

Rechner zur Berechnung der günstigsten Ernährung basierend auf Nährwerten, Kalorienbedarf und Preis pro Lebensmittel.

[Projektseite](https://smstark-projekt.de/projekte/ernaehrungsrechner.html) | [Downloads](https://smstark-projekt.de/downloads.html)

## Aktueller Stand: v1.5

Stand: 23.10.2026. Die Version enthält 1.636 Lebensmittel, erweiterte kombinierbare Parameterfilter auf Deutsch und Englisch sowie die optimierte Berechnung ganzer Mengen. Nach Änderungen wird der Plan erst per Klick neu berechnet.

- [v1.5 als ZIP herunterladen](versionen/v1.5/v1.5_Ernaehrungsrechner.zip)
- [Start, Upload-Pfade und Datenlimits](versionen/v1.5/README.md)
- [Entpackte Dateien](versionen/v1.5/entpackt/v1.5_Ernaehrungsrechner)
- [SHA-256 der ZIP](versionen/v1.5/v1.5_Ernaehrungsrechner.zip.sha256)

Das Paket enthält die Zielpfade `ernaerung/`, `en/nutrition/`, gemeinsame Header-Dateien und das Vorschaubild. Favicons sind auf Wunsch nicht enthalten. Lokal wird ein statischer HTTP-Server im Paketverzeichnis benötigt.
